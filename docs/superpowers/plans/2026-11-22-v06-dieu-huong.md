# V06 · Khung điều hướng — kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mở app là vào đúng nhóm màn theo trạng thái đăng nhập / onboarding; có thanh 5 tab với nút Ghi mở modal.

**Architecture:** Stack gốc dùng `Stack.Protected` với guard lấy từ hàm thuần `getRouteAccess`, trạng thái nằm trong store Zustand. Tab JS của Expo Router, ô Ghi là nút tùy biến mở route modal `/capture`. Màu là CSS variable của NativeWind (`vars()`), một nguồn duy nhất trong `src/theme/colors.ts` cho cả `className` và thanh tab.

**Tech Stack:** Expo SDK 58, Expo Router 58 (`Stack.Protected`, `Tabs`), NativeWind 4, Zustand, expo-symbols, expo-haptics, Jest + `expo-router/testing-library`.

**Spec:** `docs/superpowers/specs/2026-11-22-v06-dieu-huong-design.md`

> **Đã đổi khi làm:** danh sách file của Task 2 còn ghi `(auth)/` và `(onboarding)/`. Code thật đặt `sign-in.tsx`, `sign-up.tsx` ở gốc và dùng thư mục thường `onboarding/`; lý do ở mục "Cây route" của spec. Spec là bản đúng.

**Files:**

**Interfaces — Produces:**

- `type SessionStatus = 'loading' | 'signed-out' | 'signed-in'`
- `getRouteAccess(s: { status: SessionStatus; hasOnboarded: boolean }): { isReady: boolean; auth: boolean; onboarding: boolean; app: boolean }`
- `useSessionStore` (Zustand) với state `{ status: SessionStatus; hasOnboarded: boolean }`, khởi đầu `{ status: 'signed-out', hasOnboarded: false }`, và các hàm `signIn(hasOnboarded?: boolean): void`, `signOut(): void` (đặt lại `hasOnboarded` về false), `completeOnboarding(): void`.

- [ ] **Test `getRouteAccess`** bằng `it.each`, đúng bảng của spec:
      `loading` → `{ isReady:false, auth:false, onboarding:false, app:false }`;
      `signed-out` → chỉ `auth:true`;
      `signed-in` + chưa onboarding → chỉ `onboarding:true`;
      `signed-in` + đã onboarding → chỉ `app:true`. Cả ba trạng thái sau đều `isReady:true`.
      Thêm ca `signed-out` + `hasOnboarded:true` → vẫn chỉ `auth:true`.
- [ ] **Test store:** `signIn()` → `signed-in`, chưa onboarding; `signIn(true)` → đã onboarding; `completeOnboarding()`; `signOut()` sau khi onboarding → `hasOnboarded` false. Reset store trong `beforeEach` bằng `useSessionStore.setState(initial)`.
